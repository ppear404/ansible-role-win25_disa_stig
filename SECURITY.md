# Security reports

Do not post credentials, private keys, inventories, host identifiers, or raw
Evaluate-STIG results in public issues or pull requests. Report a suspected
vulnerability through GitHub's private vulnerability reporting feature if it
is enabled for the published repository. Otherwise, contact the repository
owner privately before sharing sensitive details.

This role changes Windows security configuration. Validate changes in a
representative development environment with recovery access, then assess the
effective configuration with upstream Evaluate-STIG. The optional answer file
adds a legal-notice validation comment and preserves the native finding
status. System owners handle declarations through their assessment process.
